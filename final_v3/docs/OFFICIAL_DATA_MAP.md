# Official data map

All raw inputs come from the four competition files in `config.DATA_DIR`, except the disclosed conf_lm_gated input below. Outside the disclosed exception, compatibility field names do not imply analyst or index data. Ranking formulas, size universes, walk-forward years, return labels, portfolio construction and cost assumptions remain unchanged; the expectation and filing feature meanings necessarily change as described below.

| Former external input | Official replacement | Consumer | Lost information / changed meaning |
| --- | --- | --- | --- |
| FRED TB3MS monthly yield | Cross-sectional median of `ret - ret_exc` by panel `eom` | `evaluate.market`, monthly benchmark and cash returns | Panel-implied realized monthly risk-free return, rather than a quoted annualized Treasury yield. Used for evaluation, never a formation predictor. |
| FRED TB3MS daily yield | `(1 + monthly_rf) ** (1 / N) - 1`, where N is the number of distinct supplied DSF trading dates in the full month | `report`, `evaluate.daily_metrics` | Constant daily allocation that compounds to the panel monthly rate; no daily interest-rate variation. Missing monthly rates fail rather than forward-fill. |
| FRED SP500 monthly price index | Top 500 positive-`me` securities at the preceding calendar month-end, weighted by that `me`, applied to current panel `ret` | `evaluate.market`, report comparisons, beta, correlation and plots | **Large-cap market proxy**, not S&P 500 membership or its price index. Includes supplied stock total returns. Deterministic PERMNO tie-breaking; no first-month or missing-month weight backfill. Missing constituent returns are excluded and observed weights renormalized. Internal `spx` column is retained only for interface compatibility; displayed benchmark and summary keys name the proxy. |
| FRED SP500 daily price index | Same prior-month top-500 selection and weights applied to DSF `daily_return` each day | `report`, `evaluate.daily_metrics` | Fixed formation weights each day; no current-month size selection, price index or intramonth constituent changes. Missing returns are excluded with observed weights renormalized. Daily and monthly proxy returns need not compound identically. |

Compatibility `MEANEST` is an annual per-share earnings-yield equivalent, with no invented forecast horizon or analyst counts. |

Legacy feature names retained to preserve model recipes. |

Corpus coverage is incomplete; no name matching or later issuer mapping is needed. |

The existing graph text path also uses the strictly next supplied trading day, and continues reading selected columns in Arrow batches of 2,048 filings. It never loads the full text column at once. Calendar reads and daily-return reads are chunked. Training/validation EPS labels require their separate availability date to be inside the fold cutoff; graph past-surprise features retain their stricter, strictly-before-formation convention.

## Disclosed exception

Option B (user decision, 2026-10-28) restores only the original I/B/E/S analyst-revision signal for `conf_lm_gated`, whose native universe is large/mega caps. `disclosed_ibes.py` allows only `ibes_consensus`, `ibes_price`, and `ibes_link` from `external_data/external.parquet`; every other table request raises. The signal uses the original last monthly snapshots, nearest unannounced quarterly forecast, three-month consensus change divided by snapshot price, dated ticker links, and momentum agreement gate. Other sleeves, graph inputs, evaluation and borrow assumptions retain official data.

User-supplied experiment evidence: restoring only this input moved the official book from IR -0.25 to +0.25, a measured +0.50 IR. Eight official panel stand-ins selected on 2015–2020 validation all failed. These results are prior evidence, not a rerun during this change. Carbon Arc Benzinga analyst events (insight 491) exist, but 2015–2026 coverage was quoted at $185.73–$431.24, beyond the account's $13.78 balance; not purchased.

## Removed/inert components

At endowed NAV above $50M (the mandate starts at US$1bn), `gap_micro_best` and `runway_micro` are skipped before build/load/score, with an explicit message per sleeve. Both final-score columns then use the same seven active sleeves. The nine-sleeve path at NAV <= $50M remains available.

The short-interest crowding screen is not applied because official short-interest data is absent. Main and the research harness pass `None` and print that absence; reports retain `short_interest_screen`. Missing short-interest observations have the same eligibility as the former empty table.

Active sleeve/year coverage is printed and saved as `sleeve_coverage.csv`; zero scored rows in any test year fail explicitly. Graph overlay weight and scored-row/month coverage are printed. The harness provides `drop_<active sleeve>` and `graph_off` with `--no-baseline` to measure leave-one-out effects; those measurements must be run separately.
