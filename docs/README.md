# Project guide

Stochastic Pirates finished **4th** at the 2026 McGill-FIAM Asset Management
Hackathon. This repository preserves the final strategy, its reported evidence,
and the earlier implementations that led to it.

analytics use different accounting from the local net backtest, as described
in the results guide. Editable drafts and original vendor screenshots are
not distributed separately.
